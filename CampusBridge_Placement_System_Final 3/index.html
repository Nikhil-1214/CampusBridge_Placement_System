Frequently asked questions

How do students log into the portal? +
Students log in using their assigned NSUT ID and password. The account is linked directly to their academic record in the database (CGPA, active backlogs, department, and graduation year).
How is student eligibility computed? +
Eligibility is checked in real time using the MySQL backend. A student is eligible if their CGPA meets the minimum CGPA, active backlogs are within the allowed limit, graduation year is within the eligible batch, and application deadline has not passed.
What are the default test credentials? +
You can test the system right now with:
• Admin: NSUT ID ADMIN001 · Password admin123
• Student: NSUT ID 2024NSUT1001 · Password student123
Can an administrator register new students and accounts? +
Yes. In the Admin Panel, navigate to the Users & Auth tab to create new administrator accounts and register student login accounts with custom NSUT IDs and passwords.
